# Set up the content calendar

Use one shared Content database for working drafts and publication planning.
Relate each item to its campaign so the campaign page can show its own content
without duplicating records.

## Show the work that needs attention

- Use a production board when moving drafts through writing, review, and approval
  is the main job. Group by production status and hide redundant status labels.
- Use a calendar when planning publication dates is the main job. Keep an explicit
  “No publish date” view so undated ideas remain visible.
- Use a filtered review list for drafts awaiting feedback. Open each record to
  the actual copy, script, or storyboard and the questions a reviewer must answer.

Keep production, approval, and publication distinct when the process needs all
three. A finished draft is not necessarily approved or published. Preserve
unknown owners and tentative dates; use real source information for commitments.

Show the title, channel, owner, and relevant date or state in each working view.
Keep detailed briefs and source material inside the content pages. Return to
the shared calendar and campaign from each draft.
