# Where to save: keep the workspace clean

One tidy home for plans, not pages and databases scattered across the workspace.

## Before creating anything

1. **Use a destination the person named.**
2. **Look for an existing plan** by name. If you find one, update it; never create a second plan for the same goal.
3. **Look for existing Projects and Tasks databases,** either typed `projects` and `tasks` or ones clearly used that way. Read their schemas first.

## Where things go

| What you found                                                     | Card 1 offers                                              | Result                                                                                                                                                               |
| ------------------------------------------------------------------ | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A Projects database (and Tasks)                                    | **Add to it (Recommended)** or keep it separate            | The plan becomes a project row; its tasks go in the shared Tasks database, related to that project. The home shows a view filtered to this project. No new databases |
| No Projects database; a team, ongoing work or more projects coming | **Notion Projects (Recommended)** or just this plan        | Typed `projects` and `tasks` databases, created only after this choice, in a private location unless one was named                                                   |
| Neither; a one-off plan                                            | **Project with tasks (Recommended)** or a simple checklist | A private plan page with a Tasks database inside it, or one page with a checklist                                                                                    |

## Rules

- **One plan per goal, and one Tasks database per plan.** Unless they're Notion Projects, keep the Tasks database inside its plan, never at the top level of the workspace.
- **Never create a Projects database without the card choice.** Never write into a shared or team space you guessed at.
- **In an existing database, use its fields and status steps.** Ask before adding a field.
- **Never move, rename, delete or reshare the person's pages** without a yes.
- **End with where it lives,** e.g. "Saved to Projects → Team offsite."
