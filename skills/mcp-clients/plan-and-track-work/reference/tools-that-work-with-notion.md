# Tools that work with Notion

Only use this when a plan needs something Notion doesn't do itself. The person's own tool always comes first. Partner tools only appear as options on a card, in one line, and are dropped if declined.

## Visuals: concepts or finished assets

- **Concepts** (ideas or a mood to react to): built-in image generation is fine and fast.
- **Finished assets** (readable text, a logo, brand colors, several sizes, or a matching series from the tracker): the person's design tool. If they have none, **Canva**:
  - text stays editable
  - one design can be resized
  - a template can be filled from the tracker rows
  - designs show up live on each Notion row

  Use the selected design tool’s installed instructions and current tool schemas.

- **Decide from the request when you can:** "ideas" or "what could it look like" means concepts; "ready to post," a logo or "all sizes" means finished. If it's unclear, use the visuals card in [choice cards](choice-cards.md).
- **After concepts,** when the person picks a direction, offer finished assets once.

## A web page or site

- **A simple public page:** publish the plan or a page as a **Notion Site** (`update-permission` with `isSite`, view-only, after an explicit yes, because it's public).
- **A custom site or app:** **Vercel**. The preview link and what changed go back on the plan. Use the selected hosting tool’s installed instructions and current tool schemas.

## Everything else

Meetings go to Notion Calendar and AI Meeting Notes, linked to the plan. For email, chat and audio, use the person's own tools. If a need isn't listed here, don't recommend a product; just note the need.
