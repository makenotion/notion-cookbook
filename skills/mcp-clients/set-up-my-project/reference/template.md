# First-party project template

Reference: [Projects & Tasks by Notion](https://www.notion.com/templates/notion-projects-and-tasks).
Creator verified as **Notion** on October 29, 2026. The public listing showed
4.8/5 from 8K+ ratings: evidence of substantial use, not an install count or a
category-wide ranking.

The gallery description supports combining project tracking with planning docs,
designs, and meeting notes, and choosing timeline, board, or calendar views.
Notion's [connected project management guide](https://www.notion.com/nb/help/guides/accomplish-more-with-connected-project-management)
describes Projects and Tasks databases, filtered views, and blocking relationships.

Borrow the connection between the project outcome, actionable work, and supporting
context. Our single-project layout, source handling, and optional milestones are
adaptations for agent-assisted setup, not a verified inventory of every template
property. Do not force two new databases when an existing project record or a
simple page with tasks will meet the user's need.

The extracted gallery page omits some layout detail. If an exact reproduction is
requested, inspect the accessible first-party preview and disclose any gaps.
Community templates may also inform the visual design; see
[design guidance](design.md) for inspected examples. Honor explicit user source
restrictions and verify the actual creator when attributing a reference.
