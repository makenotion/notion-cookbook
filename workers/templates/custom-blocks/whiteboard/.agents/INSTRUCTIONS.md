# Repository Guidelines

This project is a Notion Worker that declares custom blocks.

- `src/index.ts` defines the Worker and its `worker.customBlock()` declarations.
- `blocks/<name>/` holds each custom block's frontend.
- `workers.json` is generated by the CLI on first deploy.

## Custom blocks

Load the `custom-blocks` skill before writing or changing block code. It points to the full guide
that ships in `@notionhq/workers`. The installed `@notionhq/workers` and `@notionhq/custom-blocks`
packages may include more skills and docs than `.agents/skills/` lists.

## Other Worker features

For syncs, tools, webhooks, OAuth, CLI commands, and debugging runs, read `.agents/workers.md`.
