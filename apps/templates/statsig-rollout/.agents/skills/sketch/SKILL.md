# App sketch

When planning or iterating on an App workflow design with the user, read
`node_modules/@notionhq/apps/skills/sketch/SKILL.md`.
Resolve this path relative to the App project root.
Follow the instructions in that file.

If the file is missing, install the project dependencies.
If it remains missing or the sketch tools fail, tell the user the sketch skill
is not available and present the design in text instead.
